# Daily Training Sessions

Rachel's Salesforce Developer job-switch roadmap.

## Structure

Each training day is stored as a separate file:

- `Day 1`
- `Day 2`
- ...
- `Day 39`

## Daily format

Each session is ~2 hours:

- Salesforce: ~55 min
- Core Java: ~25 min
- Hands-on mini-project: ~25 min
- Git / GitHub / Harness / CI-CD: ~10 min
- Quiz / revision: ~5 min

The roadmap progresses through Apex, SOQL/SOSL, Triggers, Flows, Security, REST integrations, LWC, testing, debugging, asynchronous Apex, deployment concepts, Java fundamentals, and practical projects.
